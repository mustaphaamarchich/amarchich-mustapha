# MyCar Streamlit
Structure:
mycar_streamlit/
├── app.py
├── requirements.txt
├── dataset.csv
└── README.md

Lancement:
pip install -r requirements.txt
streamlit run app.py

Fonctionnalités: compte, profil métier, voiture, conseils, rappels,
techniciens, discussion et vidéos.

Prototype MVP: pour une version réelle, ajouter une base de données,
authentification sécurisée, géolocalisation, réservation, notifications
et messagerie persistante.
